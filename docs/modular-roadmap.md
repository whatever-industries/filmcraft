# Modular project roadmap

This is the fork's planning record for #1049. The first desktop milestone is single-editor Open → Edit → Save → Recover → Export on a local disk. A standard project remains the default exchange format. Each row below can be reviewed upstream independently, after its prerequisites. Continue on the fork if upstream declines a slice.

## Prototype audit

The prototype on `codex/modular-project-storage` was inspected at `2e02805d` with its local changes, including the uncommitted exchange and comparison implementations. The following is a source audit of those changes. Its tests describe behavior to reproduce on integration.

- **Bin exchange.** The bin-exchange panel calls `file.importProjectBin` to preview a dependency subset, including offline sources. Apply supplies the preview manifest. The exchange handler reads `Folder::load_subset`, checks that revision, rebases paths and calls `copy_selected_bin` inside one Undo step. The prototype test `import_previews_then_remaps_references_and_undo_removes_only_the_import` covers that path. Integration already rescues a historical subtree with dependencies to a standard file. Port preview, stale-preview rejection and single-step import over that traversal. Before implementation, decide when importing twice should reuse an existing source versus create an independent identity.
- **Side-by-side version comparison.** The versions panel calls `project.compareModuleVersions`; the discovery handler calls `Folder::version_subset` and compares the result with another revision or the open project. It reports member or clip changes and changed sources. The prototype UI test `deleted_cut_can_be_found_compared_and_recovered_from_the_file_menu` and `search_deleted_by_old_path_then_compare_and_recover_without_changing_live_items` cover that workflow. Integration already lists revisions and rescues old cuts and bins. Port a read-only comparison first. Review replacement of live edits, changed dependencies, and cross-bin moves separately from comparison and restore-as-copy.
